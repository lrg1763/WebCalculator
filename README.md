# WebCalculator

Простой веб-калькулятор на HTML, CSS и JavaScript. Работает в браузере без сборки и дополнительных зависимостей.

## Возможности

- Сложение, вычитание, умножение и деление
- Работа с десятичными числами
- Очистка экрана (AC)
- Обработка деления на ноль
- Адаптивная вёрстка

## Запуск

Откройте `index.html` в браузере. Либо поднимите локальный сервер в корне проекта:

## Структура проекта

- `index.html` — разметка и кнопки калькулятора
- `style.css` — стили, сетка кнопок, шрифты
- `script.js` — логика вычислений и обработка нажатий
- `fonts/` — шрифт ONYSemimonoBeta (Regular и Black)
- `favicon_io/` — иконка сайта
