# WebCalculator

Веб-калькулятор на чистом HTML, CSS и JavaScript. Работает в браузере без сборки и зависимостей.

## Возможности

- Четыре арифметические операции: сложение, вычитание, умножение, деление
- Ввод десятичных чисел
- Очистка экрана (AC)
- Обработка деления на ноль (показ ошибки и сброс через секунду)
- Ограничение ввода: на экране не более 12 символов (цифры и точка)
- Поддержка клавиатуры: цифры, точка/запятая, операторы (`+` `-` `*` `/`), `Enter` или `=` — результат, `Escape` или `Backspace` — очистка
- Адаптивная вёрстка и центрирование по экрану

## Запуск

Откройте `index.html` в браузере.


## Структура проекта

```
WebCalculator/
  index.html      — разметка калькулятора и кнопок
  style.css       — стили, переменные, шрифты
  script.js       — логика вычислений, делегирование кликов, обработка клавиатуры
  fonts/          — шрифт ONYSemimonoBeta (Regular, Black)
  favicon_io/     — иконка сайта
```

## Технологии

- HTML5: семантическая разметка, data-атрибуты, preload шрифтов
- CSS3: переменные, Grid, плавные переходы, опционально тёмная тема
- Ванильный JavaScript: один обработчик на блок кнопок (делегирование), обработка клавиатуры, состояние в одном объекте, округление результата до 12 символов
